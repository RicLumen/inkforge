# 模型短测

同一段提示词，六个模型各跑一次，思考强度都是 medium，结果原样贴出，没有改动。只考两道 50–150 字的小题，用来看各模型写网文冲突的手感，选哪个按你自己的口味。

## 提示词

```text
写一段中文短篇网文（知乎盐选/番茄短篇风格），50–150 字。
情景：（见下面两题）
分段用网文手机阅读的节奏：短句为主，每段一到三句，不要写成作文式的大段；也不要一句一段，相关的动作和对话放在同一段，读起来要连贯。
只输出正文，不要标题和解释。
```

| 模型 | 调用方式 |
| :-- | :-- |
| GPT-6 Astra | Codex，`gpt-6-astra` |
| GPT-6.1 Terra | Codex，`gpt-6.1-terra` |
| Gemini 3.8 Flash | Antigravity CLI，`gemini-3.8-flash-medium` |
| Gemini 4 Argon | Antigravity CLI，`gemini-4-argon-medium` |
| Claude Opus 5.5 | Antigravity CLI，`claude-opus-5-5-medium` |
| Claude Sonnet 5.5 | Antigravity CLI，`claude-sonnet-5-5-medium` |

## 题 1：婆婆过户

> 年夜饭桌上，婆婆当着全家宣布把老房子过户给小叔子，可首付是女主出的。写这场对话。

### GPT-6 Astra

婆婆放下筷子，笑着宣布：“老房子过完年就给老二过户，都是一家人，谁也别计较。”

我夹菜的手停了：“首付三十万是我出的，您忘了？”丈夫在桌下踢我：“大过年的，别扫兴。”

“你嫁进来，钱不就是我们家的？”婆婆沉下脸。

我点开手机银行，把那笔转账推到她面前：“那借条上，您怎么没写一家人？”

### GPT-6.1 Terra

婆婆举起酒杯：“老房子已经过户给小叔了，他还没结婚，需要房子。”

一桌人都看向我。小叔低头夹菜，筷子却停在半空。

我放下碗：“首付三十万，是我出的。”

婆婆笑了笑：“一家人，还分这么清？”

我打开手机，把转账记录推到桌子中央：“那正好。既然是一家人，今晚把钱还我，欠条就不用写了。”

小叔的筷子掉在了桌上。

### Gemini 3.8 Flash

婆婆夹了块鸡腿放到小叔子碗里，笑得合不拢嘴：“趁今天全家齐整，我把城东那套老房子过户给小军，当作他结婚的婚房。”

满桌欢呼附和，我咽下嘴里的冷菜，慢条斯理地放下筷子。

“妈，那套房首付六十万，可全是我婚前垫的。”我直视着她，语气平静，“过户可以，先把首付连本带利还我。”

包厢里瞬间死寂，婆婆脸上的笑骤然僵住了。

### Gemini 4 Argon

年夜饭上，婆婆举杯宣布：“年后我就把老房子过户给耀祖当婚房！”小叔子乐得直拍桌，老公却闷头扒饭不敢吭声。

我啪地搁下筷子，冷笑出声。“妈，那房子的首付是我出的，您转手送人，问过我吗？”

婆婆脸色骤沉，把酒杯重重往桌上一墩：“嫁进门就是一家人，你的钱就是咱家的钱！当嫂子的别这么自私！”

### Claude Opus 5.5

年夜饭刚上桌，婆婆清了清嗓子：“老房子我过户给小军了，他要结婚。”

全家都看向我。老公低头夹菜，一声不吭。

我放下筷子，笑了：“妈，首付八十万是我出的，转账记录都在。”

婆婆脸一沉，筷子拍在桌上：“嫁进来了，还分什么你的我的？”

“行啊。”我掏出手机，“那就离婚，咱们去法院分。”

### Claude Sonnet 5.5

婆婆放下筷子，清了清嗓子。
"老房子，下个月过户给你小叔。"

满桌静了。我夹菜的手停在半空。

"妈，那房子的首付，是我出的。"
"你出的又怎样？你嫁进来，钱就是陈家的。"婆婆眼皮都没抬。

我笑了，放下筷子，从包里抽出一份文件。
"巧了，转账记录和借款协议我都带了。您儿子亲手签的字。"

婆婆的脸，瞬间白了。

## 题 2：电梯裁员

> 公司裁员名单里有女主，名单是她带出来的徒弟递上去的。写两人在电梯里的一分钟。

### GPT-6 Astra

电梯门合上，徒弟伸手替我按了一楼，没敢看我。「师父，名单的事，我也没办法。」

我看着跳动的楼层：「你入职那年，转正名单里也没你。」

她猛地抬头，我替她理了理翻起的工牌。「那时候，我有办法。」

电梯到了一楼，她挡住门：「你能不能别告诉别人？」

我拨开她的手，走了出去。

### GPT-6.1 Terra

电梯门合上时，徒弟攥紧了工牌。

“姐，名单是我递的，但不是我定的。”

我点点头，替她按了三十六楼。她升职的消息，我早上就听说了。

数字一层层跳动。她忽然问：“你恨我吗？”

“你刚进公司时，我教过你怎么做汇报。”我看着门上映出的她，“第一页，别把自己的名字写成别人的。”

她脸上的血色褪了。叮的一声，三十六楼到了。

门开着，她没动。我按住开门键：“去吧，董事会还等着你汇报我的方案。”

### Gemini 3.8 Flash

封闭的轿厢急速下坠。小林死死攥着那份刚递上去的裁员名单，指尖泛白，声音发颤：“师父，上面逼得紧，我也是身不由己……”

我伸手替他理正新换上的总监工牌，迎上他仓皇躲闪的视线。我弯唇笑了笑：“业务是我教的，踩着师父往上爬这招，你倒是无师自通。”

叮的一声，一楼到了。电梯门向两侧敞开，我踩着高跟鞋径直迈进光里，没再看他一眼。

### Gemini 4 Argon

电梯数字不断往下跳。我盯着反光的金属壁，忽然开口：“裁员名单，是你递上去的吧？”

身后的小陈身体一僵，死死攥紧了文件夹。他不敢看我，声音发虚：“姐，总监说二选一，我也没得选……”

“叮”的一声，一楼到了。我替他正了正领带，轻笑出声：“下周的竞标，核心底牌我可没教过你。祝你好运，新主管。”

### Claude Opus 5.5

电梯门合上，只剩我和林晓。她盯着跳动的数字，攥紧了怀里的文件夹。

"师父，名单是上面让我交的。"她声音很轻，"我也没办法。"

我没看她，只问："你交上去那份方案，第三页的数据核对过吗？"

她一愣，脸色一点点白了。那是我教她的第一课：交出去的东西，要经得起查。

叮——一楼到了。我先走出去，没回头。

### Claude Sonnet 5.5

电梯门合上，只剩我和林晓。

她手里攥着工牌，指节发白。我先开了口：“名单是你交的吧。”

她肩膀一颤，没敢抬头。“师父，我……”

“别叫我师父。”我看着跳动的楼层数字，“但那份客户资料，是我手把手教你整理的。你用得很顺手。”

叮，一楼到了。

我走出去，没回头：“好好干，别让我白教。”
