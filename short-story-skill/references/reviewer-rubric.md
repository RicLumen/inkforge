# 评审量表（全部通过才算不用再改）

不要先按超短或中短分档评，格式和单章字数在两档里是一样的，档位是写完之后再分类的。

评审先查作者常犯的拒稿点，见 `rejection-checklist.md`：主线不清晰、矛盾冲突悬浮、整体节奏慢、场景心理外貌描写过多且无信息增量、钩子不足。这五条任何一条不通过，本批就不能算不用再改，其他项写得再好也要先修这五条。下面的八项是完整量表，拒稿点检查和八项都要通过。

1. 开头钩子：引言第一段是否立住冲突或悬念，读者不读第二段就想知道接下来发生什么。不通过的典型表现是前三句全是环境铺垫或人物介绍。

2. 章节钩子与截断点：每一章结尾是否留了钩子，引导读者继续往下读；全篇的付费截断点是否在全文三分之一到一半多一点的位置，截断点前核心冲突和悬念是否已经立住。

3. 单章字数与切分：引言在六十到两百字之间；单章在五百到一千字之间；文本没有切得过碎，也没有一章写成两千字的长章。计数不含章节数字编号和空行，含标点。超出范围即不通过，不管写得多好。一万字左右尽量十二章以内是参考，不是所有篇幅的硬上限，篇幅长了章数自然多，关键是单章范围和不切碎。

4. 视角与情绪基调：默认第一人称，中途尽量不换视角，非要换只能放在截断点之后；全篇情绪基调没有中途改变；用户指定其他视角时按用户指定的评。

5. 节奏与信息增量：节奏是否快，是否有冲突、解决、再出现新冲突的循环；场景、心理和外貌描写是否有信息增量，没有信息增量的描写和形容词是否已经删掉；对话是否推进信息，不要只数对话占比，对话占比不再是硬性项。

6. 前后连贯与原创性：本批和前面章节在时间线、人物状态、已埋的线上面没有矛盾；没有照搬已知作品的情节、台词和设定，疑似雷同处必须标出来。

7. 标点格式与规范用字：换行处有终止标点；对话用冒号加双引号，引号内有终止标点；标题无书名号、结尾无标点；错别字、“的地得”、病句已经检查；没有空行，换行直接写。

8. 古言语感：没有现代口语、网络用语、现代制度词汇混入古言语境，称谓、礼节、器物符合用户设定的朝代背景，不确定的地方标注出来问用户，不要编一个似是而非的古称。

评审输出格式：八项各一行，通过写“通过”，不通过写“不通过：章节号 + 原句 + 改法”。八项全部通过时，最后一行写“结论：不用再改”。
