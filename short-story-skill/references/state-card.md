# 状态卡

三个角色之间靠这张卡传递信息。由构思角色填写和更新，写作角色和评审角色只读；评审对卡有意见写在评审意见里，由构思角色下一批改。

```
主线一句话（主角要什么 / 阻碍是什么 / 失败会怎样）：
锚点描述（主角彻底决裂、亮出底牌、真相揭开或冲突无法回头的那件事）：
锚点章号（可改，改了注明）：
锚点之后计划章数（每批重估）：
预计总章数范围（上下浮动 1–2 章，如预计 12 章则填 11–13 章）：
情绪基调：
视角 / 人称：
已写章节：
上一批摘要（不超过 3 句，只写发生的事）：
时间线（如：第 1 章 三月初三白天；第 2 章 三月初三夜）：
人物状态（如：林晚 已知绣样有问题，未告诉任何人）：
未收伏笔（一条一行，注明埋在第几章；收线后标“已收于第 N 章”，不删）：
```
