# 中文短篇网文写作

用户想用 AI 写中文短篇网文时使用。不用于长篇、分卷大纲、世界观搭建、英文短篇或纯文学短篇。

## 开始前

- 问用户想写什么（剧情或一句话梗概）。题材由用户定，不替用户编。
- 问大致篇幅和打算发在哪里。

## 篇幅

开局不分超短、中短两档（两档格式和单章字数一样），也不定最终字数。构思角色在状态卡里定预计总章数范围（上下浮动 1–2 章，如预计 12 章则填 11–13 章）和锚点章号，剧情走向变了就更新状态卡。

写完再分类，只作参考：约 6000–25000 字为超短，约 25000–80000 字为中短。单线冲突的稿子 1 万字左右即可，约 10–12 章，别切太碎；多线、多反转的可以写到 2–3 万字。

## 正文规则

- 引言：无标题，约 150 字（60–200 字），第一段立住冲突或悬念。
- 单章 500–1000 字。不到 500 字评审会提醒，优先合并相邻章或补情节事件，不用心理描写凑字数。超过 1000 字要处理：先删不推动情节、不制造悬念的描写和重复叙述，仍超就拆章并重排编号。
- 每章结尾留钩子。节奏要快，问题不断升级或反转，形成“冲突—解决—新冲突”。
- 截断点：主角彻底决裂、亮出底牌、核心真相揭开或主冲突升级到无法回头的那一章是锚点章，截断点在锚点章之后。锚点累计（引言加第 1 章到锚点章）在全篇写完后应占全文 35%–55%。写作中只记录是否已写到锚点章，不看占比。写完后不在范围内，就调整锚点前后的篇幅或挪锚点，改状态卡并重评受影响的批次。截断点前立住核心冲突和悬念，更大的反转放在后面。发付费平台时，它就是付费卡点。
- 基调动笔前定好，全篇不变。结构起承转合，写到自然收束，不为凑字数拉长或硬删。
- 视角默认第一人称，尽量不换；要换放在截断点之后。用户指定了视角的，以用户要求为准。
- 删掉不推动情节、不制造悬念的场景、心理和外貌描写，少用形容词。对话要推进剧情或交代信息。对话占比没有硬性要求，但本批对话占比低于 15% 时，评审要点出来，说明哪些交代信息的旁白适合改成对话。语言问题按 `references/anti-ai-checklist.md` 查。
- 标点：换行处有终止标点；引出对话用冒号加弯引号 “”，引号内有终止标点；不用直引号。
- 标题：可用标签化词语和热门表达，多用对比和反转，不用生僻词和过激的词；不加书名号，末尾不加标点。
- 用字：校对错别字和“的地得”，查病句；段间不空行。

## 三个角色

- 构思：每批给下一批方向，不超过 5 条，每条一句话，接住上一批留下的线；维护状态卡 `references/state-card.md`。
- 写作：按方向写一批，遵守正文规则。一次只写一批，不一次生成全篇。
- 评审：按 `references/reviewer-rubric.md` 八项逐项评，每条意见指到具体章节和原句。评审标准以量表为准，循环中不加新标准。

提示词在 `prompts/conceiver.md`、`prompts/writer.md`、`prompts/reviewer.md`。

评审最好在独立子 agent 或独立会话里运行，只给它四样东西：本批正文、状态卡、计数脚本输出、量表。不给累计全文（全篇写完后的核对除外）、写作角色的思路和构思角色给的方向。平台没有子 agent 时（如 Claude 网页版），评审前只重读本批正文并引用原文。

## 每批流程

1. 开局：构思角色写第一版状态卡。
2. 构思角色给方向，写作角色写本批（第一批是引言加第 1–4 章），然后跑计数脚本。
3. 评审按量表评；写作角色逐条改，说明改了哪里，没改的说明理由。
4. 评审给出“不用再改”并附八项结论和脚本输出，这一批结束。

这一批交给用户决定的情况：同一批改到第 3 轮仍有分歧（给出分歧点和两个版本）；跑不了脚本（评审注明“未跑脚本，字数未核实”）。没有子 agent 的平台上，每批都要用户确认后再继续。

## 计数

每批写完，对累计全文（引言加已写全部章节）运行：

```
python3 scripts/count_chapters.py 全文.txt --batch-from <本批首章>
```

输出每章字数和是否在范围内，以及本批对话占比。字数含标点，不含章节号和空行。全篇写完后加 `--anchor-chapter N --final`，得到截断点占比。

## 全篇写完后

评审拿到全文，给最终结论前做两项核对：

1. 对照全文核对状态卡的时间线、人物状态和未收伏笔。
2. 不看状态卡，直接查全文是否自洽：人名称谓、物件去向、谁知道什么、时间线。

有出入先改，重评受影响的批次，再跑 `--final` 核对截断点。

## 发布

发布前由用户自己审稿，按平台规则查原创性和敏感词。skill 不代为投稿或发布。
